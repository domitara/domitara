# Asset IDs

Every item gets an auto-generated asset ID (`DT-XXXXXX`) when it's created — a short code you
can physically attach to the item (on a printed sticker, engraved tag, etc.) so it can be
looked up by scanning or typing the code rather than searching by name.

![Asset IDs screen](/img/web/asset-ids.png)

The **Asset IDs** screen lists every item together with its code, location, and status, and
lets you filter to items that have one vs. items that don't. Select items with the checkboxes
to build a batch — this is the screen to use when you're about to print a sheet of labels for
several items at once, or before you order QR/barcode stickers.

An item's asset ID also shows on its own detail page under **Quick facts**.

:::note
Label/QR printing and bulk asset-ID generation are actively evolving — if a button here
doesn't do what you expect yet, check the changelog or open an issue.
:::
